# SO Aroma Diffuser S6 для Home Assistant

[English](README.md)

Интеграция управляет диффузором **SO Aroma Diffuser S6 (bwj.diffuser.s6)** локально по Bluetooth.

- Включение и выключение распыления, длительность и интервал.
- Подсветка с цветовым кругом Home Assistant.
- Таймер выключения подсветки на 1–120 минут с запуском и отменой. Таймер сохраняет выбранный цвет и не меняет режим распыления.
- Заряд аккумулятора и состояние зарядки.

## Установка

1. Подключите диффузор к **Xiaomi Home**. Для Home Assistant понадобится Bluetooth-адаптер рядом с диффузором или [прокси ESPHome](https://esphome.io/components/bluetooth_proxy/) с активными подключениями.
2. Запустите у себя [Xiaomi Cloud Tokens Extractor](https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor). Выберите регион Xiaomi Home и найдите устройство **bwj.diffuser.s6**. Скопируйте **MAC** и **TOKEN**. Для этой модели нужен **TOKEN** из 24 шестнадцатеричных символов. Утилита показывает **BLE KEY** в отдельном поле.
3. В меню **⋮ → Пользовательские репозитории** в HACS добавьте URL этого репозитория с типом **Интеграция**. Скачайте **SO Aroma Diffuser S6** и перезапустите Home Assistant. При ручной установке скопируйте **custom_components/aroma_s6** в одноимённый каталог конфигурации Home Assistant и перезапустите его.
4. Откройте **Настройки → Устройства и службы → Добавить интеграцию → SO Aroma Diffuser S6**. Введите MAC и токен.

Нужен Home Assistant 2026.3 или новее. Интеграция проверена на Home Assistant Core 2026.11. После настройки она общается с устройством по Bluetooth. Токен храните в своей установке и скрывайте на скриншотах и в журналах, которыми делитесь.

## Подсветка и таймер

В карточке диффузора нажмите на название **«Подсветка»**, затем на радужный кружок **«Цвет»**. Для выключения с задержкой укажите минуты в поле **«Таймер подсветки»** и нажмите **«Запустить таймер подсветки»**. Кнопки и настройки доступны для автоматизаций Home Assistant.

Если диффузор недоступен, попробуйте разбудить его физической кнопкой, поднести к Bluetooth-адаптеру или прокси и подключить к USB-питанию. Если Xiaomi Home удерживает соединение, закройте в нём карточку диффузора. Оттенок на корпусе может отличаться от цвета на экране из-за ограничений светодиодов.

Это сторонняя интеграция. Другие модели диффузоров SO и Xiaomi пока не проверялись.
